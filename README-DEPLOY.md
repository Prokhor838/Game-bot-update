# GAME BOT 2.0 — сервер + Mini App (версия 2.1)

Все файлы лежат в одной папке (без вложенных), чтобы их можно было загрузить на GitHub с iPhone.

## Файлы
- `index.html` — приложение (7 игр, дизайн и функции сохранены) + подключение к серверу + «Админ-панель».
- `server.js` — сервер: API, раздача `index.html`, резервные копии. Внешних пакетов нет.
- `auth.js` — проверка подписи Telegram `initData`, разбор `ADMIN_IDS`.
- `catalog.js` — каталог кристаллов (названия, описания, редкости, цены из прежнего кода).
- `schema.sql` — схема SQLite (создаётся автоматически; существующие данные не стираются).
- `test.js`, `package.json`, `env.example` — автотесты, запуск, пример переменных окружения.
- `index.original.html` — исходное приложение до изменений (только для сохранности; на хостинг не нужно).

## Переменные окружения (вводите на хостинге; в GitHub их не кладите)
| Имя | Обязательно | Что это |
|---|---|---|
| `BOT_TOKEN` | да | токен бота из @BotFather |
| `ADMIN_IDS` | да | ваш числовой Telegram ID (несколько — через запятую). Узнать: бот @userinfobot |
| `CASINO_ADMIN_IDS` | нет | дополнительные админы, объединяются с `ADMIN_IDS` |
| `DB_PATH` | рекомендуется | путь к файлу базы на **постоянном диске**, например `/data/gamebot.db` |
| `BACKUP_DIR` | нет | папка копий, по умолчанию рядом с базой (`backups/`) |
| `PORT` | обычно задаёт хостинг | порт |

Права админа определяются только по числовому ID, подпись `initData` проверяется на сервере при каждом запросе.

## Как выбрать хостинг (главное — постоянное хранение SQLite)
Нужен хостинг, где работает **Node.js версии 22.13 или новее** и есть **постоянный диск (volume)**, примонтированный к папке, например `/data`. Тогда `DB_PATH=/data/gamebot.db`. Без постоянного диска файл базы **стирается** при каждом перезапуске или обновлении, и все балансы пропадут. GitHub Pages не подходит (нет сервера).
Проверьте на странице тарифа выбранного сервиса (условия меняются): 1) есть ли persistent disk/volume и входит ли он в бесплатный тариф; 2) версия Node (часто задаётся переменной `NODE_VERSION=22`); 3) не «засыпает» ли сервис надолго (бот будет открываться медленно); 4) команда запуска `npm start`. Подходящие типы: Fly.io и Railway (volumes), Render (persistent disk), обычный VPS. Если бесплатного постоянного диска нет, используйте дешёвый платный.

## Резервные копии и их проверка
Сервер раз в 6 часов делает копию базы (`VACUUM INTO`) в `BACKUP_DIR`, хранит последние 7 дней. Проверка:
1. После запуска откройте приложение → Настройки → «Админ-панель» → вкладка «Журнал»: в блоке статистики строка «Резервные копии» должна показать файл `gamebot-ГГГГ-ММ-ДД.db`.
2. Папка копий должна находиться **на том же постоянном диске**, иначе она тоже пропадёт.
3. Копия на том же диске не защищает от потери самого диска. Включите автоматические снимки диска (snapshots) у хостинга и раз в месяц проверяйте, что восстановление работает: создайте тестовый аккаунт, сделайте снимок, измените данные, восстановите и убедитесь, что данные вернулись.
4. Скачать файл базы с iPhone через это приложение нельзя. Используйте инструменты хостинга.

## Загрузка на GitHub с iPhone (без компьютера)
1. Сохраните файлы из чата в приложение «Файлы» (если пришёл ZIP — коснитесь его, и он распакуется).
2. В Safari откройте github.com → войдите → New repository → имя `gamebot-server` → **Private** → Create.
3. Add file → Upload files → выберите по очереди из «Файлов»: `index.html`, `server.js`, `auth.js`, `catalog.js`, `schema.sql`, `package.json`, `test.js`, `README-DEPLOY.md` (файл `env.example` можно тоже) → Commit changes.
4. Никогда не загружайте файлы с токеном. База создаётся на хостинге и в репозиторий не попадает.
5. На хостинге: New → Web Service → подключите репозиторий → Start command `npm start` → добавьте переменные из таблицы выше → подключите постоянный диск (mount path `/data`) → Deploy.
6. После деплоя откройте адрес вида `https://...` в Safari: должна появиться надпись «Откройте приложение через Telegram-бота» (так и задумано). Адрес `/healthz` должен вернуть `{"ok":true}`.

## Подключение к боту
В @BotFather: `/mybots` → ваш бот → Bot Settings → Menu Button → Configure menu button → отправьте **новый** HTTPS-адрес сервера. Остальные настройки бота не меняются, кнопка запуска остаётся.

## Что реально защищено, а что нет
Сервер сам решает и проверяет: баланс, ставки и вращения казино, открытие кейсов (случайность на сервере), продажу кристаллов, ежедневную награду (по UTC), достижения, все админ-операции. Повторные запросы с тем же идентификатором не дают двойного начисления, а баланс в БД не может быть отрицательным.

**Не защищено полностью:** результаты «Крестики-нолики», «Угадай число», «Викторина», «Дурак», «Блоки» считаются в браузере, и сервер не может проверить, что партия была сыграна честно. Сервер ограничивает награды фиксированными суммами, допустимыми значениями, паузой не менее 3 секунд между наградами одного вида и общим лимитом 3000 монет в сутки на такие награды. Технически подкованный игрок всё равно может набирать эти награды в пределах лимита. Полная защита потребует вести сами игры на сервере.

## Перенос старого прогресса
Локальные данные браузера привязаны к адресу сайта. Если приложение откроется по новому адресу, старые данные там не видны, и перенос невозможен. Кнопка «Импортировать старый прогресс» (Настройки) работает только если старые данные оказались на том же адресе. Импорт один раз, с жёсткими лимитами (до 1000 монет, до 5 шт. каждого кристалла) и без проверки сервером. Данные других игроков автоматически перенести нельзя: у них нет механизма передачи. Все начинают с 500 монет.

## Что проверить после публикации (в реальном Telegram)
1. Приложение открывается из кнопки меню бота, видны ваше имя и баланс 500.
2. Ежедневная награда, кейс, продажа кристалла, казино меняют баланс и после перезапуска значения сохраняются.
3. Перезапустите сервис на хостинге: баланс и коллекция остались (диск постоянный).
4. Вы видите «Админ-панель» в Настройках, а второй аккаунт — нет. Откройте ссылку API админа вторым аккаунтом (если сможете) и убедитесь в отказе.
5. Админ: выдача и изъятие монет и кристаллов себе и другому, смена цены, журнал.
6. «Дурак» (пауза бота около 2 секунд), перетаскивание в «Блоках» на iPhone и Android, светлая тема.
7. Резервная копия появилась в статистике.
